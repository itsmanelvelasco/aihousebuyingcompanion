Know what’s behind the answer.

Official municipal snapshots and researched opportunities are combined by town code. Coverage is a pilot, not all of Catalonia. Historical housing averages are not available listings; school locations do not confirm places or walking routes. Incentive eligibility and application status are separate checks.

Running relo.cat yourself?

This checkout has a local demo endpoint with no MCP sign-in. Use fictional profiles for the connected demo. A public service needs authentication and access controls before sharing it broadly.

Local server and key setup
npm run dev:stack

The MCP endpoint is http://127.0.0.1:8787/mcp. Cloud agents need an operator-provided HTTPS URL, or a supported private tunnel. A local address only works for agents running on the same machine.

Set TREG_TOKEN in the server environment before starting it to enable live home searches. This is a provider key for the server—not a credential to paste into your agent. Town research works without it.
