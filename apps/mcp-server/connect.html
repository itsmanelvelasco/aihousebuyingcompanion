About the data

Sources include official municipal statistics and dated relocation research for three pilot towns. Housing averages describe the local market. Check listing availability, school admissions and walkability separately. Incentives show application status and household eligibility separately.

Local server and live listing setup 
npm run dev:stack

The local MCP endpoint is http://127.0.0.1:8787/mcp. Cloud agents need an HTTPS URL from your server operator or a supported private tunnel.

Set TREG_TOKEN in the server environment to enable live example links. The provider may charge for searches. Town research runs without the key.
